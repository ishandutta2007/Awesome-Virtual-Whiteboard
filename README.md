# Awesome-Virtual-Whiteboard

# Top Virtual Whiteboard Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Collaborative Canvases, Online Whiteboarding, Diagram Sketching & Real-Time Visual Collaboration*  
**Last updated: October 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Virtual Whiteboards**. These tools provide infinite (or large) canvases for sticky notes, diagrams, workshops, and real-time multiplayer sketching.

**Examples** include Lucidspark, Miro, Mural, Conceptboard, Microsoft Whiteboard, Stormboard, Bluescape, InVision Freehand, Freeform, Klaxoon, and **tldraw** (`tldraw/tldraw`)—a highly performant collaborative whiteboard / canvas toolkit.

**Open-source emphasis**: Fully permissive open whiteboards are fewer than commercial suites, but **Excalidraw** leads as MIT-licensed and self-hostable. **tlDraw** source is public with commercial licensing for production SDK use—check current terms. Other open canvas and diagram tools expand the toolkit. This section lists every significant relevant project found.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Miro, Mural, Lucidspark, Klaxoon](https://miro.com/)**  
  Leading collaborative whiteboard platforms—templates, workshops, sticky notes, and enterprise facilitation features.

- **[Microsoft Whiteboard, Conceptboard, Stormboard, Bluescape](https://www.microsoft.com/en-us/microsoft-whiteboard)**  
  Team whiteboarding integrated with productivity suites or designed for large visual workspaces.

- **[tldraw.com, Excalidraw+](https://tldraw.com/)**  
  Hosted products from popular canvas projects—free tiers and paid collaboration features.

- **[Other commercial virtual whiteboard platforms](https://www.mural.co/)**  
  Additional design, agile, and education-focused online boards.

## Open-Source GitHub Projects

- **[Excalidraw](https://github.com/excalidraw/excalidraw)**  
  Leading MIT-licensed virtual whiteboard—hand-drawn style, end-to-end encryption options, self-hostable, and ideal for diagrams and technical sketching.

- **[tldraw](https://github.com/tldraw/tldraw)**  
  Highly performant collaborative canvas—source available; production commercial use of the SDK typically requires a license (verify current tldraw license before embedding in products).

- **[Whiteboard (various self-hosted)](https://github.com/search?q=collaborative+whiteboard+self-hosted)**  
  Community collaborative whiteboard apps built for Docker deployment and team intranets.

- **[WBO (Web Whiteboard Online)](https://github.com/lovasoa/whitebophir)**  
  Open simple collaborative whiteboard—lightweight real-time drawing for classrooms and meetings.

- **[OpenBoard / education whiteboards](https://github.com/OpenBoard-org/OpenBoard)**  
  Open interactive whiteboard software oriented toward teaching and presentations.

- **[draw.io / diagrams.net](https://github.com/jgraph/drawio)**  
  Open diagramming application—not a freeform sticky-note board, but widely used for structured collaborative diagrams (self-host available).

- **[Fossil / other canvas engines](https://github.com/search?q=infinite+canvas+open+source)**  
  Community infinite-canvas and sketch libraries usable as whiteboard building blocks.

- **[CryptPad / collaborative suites with boards](https://github.com/cryptpad/cryptpad)**  
  Open privacy-focused collaboration suite that can include drawing and board-like documents.

### Additional Strong Open-Source Options

- **Best MIT self-hosted board**: Excalidraw.
- **Canvas SDK (check license)**: tldraw for product embedding when licensed.
- **Minimal real-time board**: WBO.
- **Structured diagrams**: diagrams.net (draw.io).
- **Composable stacks**: Excalidraw or WBO self-host + SSO reverse proxy; or embed open canvas in your app under a compliant license.
- Commercial boards still lead for workshop templates, enterprise admin, and large-scale facilitation analytics.

**Frameworks for building custom systems**:  
**Excalidraw** for open collaborative sketching; **WBO** for simple classrooms; **draw.io** for formal diagrams; **tldraw** when you need a canvas SDK and accept its commercial terms.  
Fully open virtual whiteboarding is practical for technical teams; enterprise workshop UX is still dominated by Miro-class SaaS.

## Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.
- Collaborative boards may hold sensitive strategy and personal data—control sharing links, enforce SSO where needed, and review retention. License terms matter: “source available” is not always OSI open source for commercial embedding.
- Open-source boards offer privacy and self-hosting. Commercial platforms shift collaboration infrastructure to the vendor. Neither replaces facilitation skill and clear workshop goals.
